OPTION 1: Easiest (No Maven Required)
   Double-click: run-java-simple.bat
   
   What it does:
   → Downloads JSON library automatically
   → Compiles ExpenseTrackerClient.java
   → Runs the program
   → Shows all tests passing

OPTION 2: With Maven
   Open terminal and run:
   mvn clean install
   mvn exec:java -Dexec.mainClass="ExpensifyClient"

OPTION 3: Manual Compilation
   1. Download json-20231013.jar to lib/ folder
   2. javac -cp "lib\json-20231013.jar" ExpensifyClient.java
   3. java -cp ".;lib\json-20231013.jar" ExpensifyClient
